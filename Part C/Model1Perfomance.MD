# Model 1 Performance – Logistic Regression

## 1. Introduction

Model 1 is a Logistic Regression classifier developed in Part B to predict the binary customer churn outcome in the public Bank Customer Churn Modelling dataset.

The public dataset is being used as a proxy for the STADIOEquities project. The eventual STADIOEquities objective is to predict whether a client becomes dormant within six months.

## 2. Model Configuration

The Logistic Regression model uses the following hyperparameters:

| Hyperparameter | Value |
|---|---|
| C | 1.0 |
| Solver | liblinear |
| Maximum iterations | 1000 |
| Class weight | balanced |
| Random state | 42 |

The model is implemented together with the preprocessing pipeline developed in Part B.

## 3. Performance Metrics

The following metrics are used:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion matrix

These metrics are appropriate because the target variable is a binary classification outcome and the classes are imbalanced.

### Accuracy

Accuracy measures the proportion of all observations that were classified correctly.

### Precision

Precision measures the proportion of observations predicted as churn that were actually churn cases.

### Recall

Recall measures the proportion of actual churn cases that were correctly identified.

Recall is particularly relevant to the STADIOEquities problem because failing to identify an at-risk client could mean that the client is not considered for an appropriate retention or engagement intervention.

### F1-score

The F1-score provides a combined measure of precision and recall.

### ROC-AUC

ROC-AUC measures the ability of the model to distinguish between the two classes across different classification thresholds.

### Confusion Matrix

The confusion matrix presents:

- True Positives
- True Negatives
- False Positives
- False Negatives
